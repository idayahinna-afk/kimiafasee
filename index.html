Capaian Pembelajaran Fase E

Capaian umum. Pada akhir Fase E, peserta didik mampu merespons isu-isu global dan berperan aktif memberikan penyelesaian masalah: mengidentifikasi, mengajukan gagasan, merancang solusi, mengambil keputusan, dan mengomunikasikannya dalam bentuk proyek sederhana atau simulasi visual, terkait energi alternatif, pemanasan global, pencemaran lingkungan, nanoteknologi, kimia sehari-hari, serta pemanfaatan limbah dan bahan alam, untuk mendukung SDGs.

Pemahaman kimia. Mengamati, menyelidiki, dan menjelaskan fenomena sesuai kaidah kerja ilmiah; menerapkan konsep kimia dalam pengelolaan lingkungan termasuk pemanasan global; menuliskan reaksi kimia dan menerapkan hukum-hukum dasar kimia; memahami struktur atom dan aplikasinya dalam nanoteknologi.

Keterampilan proses. Mengamati; mempertanyakan dan memprediksi; merencanakan dan melakukan penyelidikan; memproses dan menganalisis data; mengevaluasi dan merefleksi; mengomunikasikan hasil.

          Panduan Guru

          Cara memakai media ini di kelas dan cara menerbitkannya di GitHub Pages.

          Mempresentasikan satu pertemuan

          1. Buka Presentasi, pilih pertemuan sesuai Program Semester, lalu tekan Mulai presentasi.
          2. Tekan F atau tombol Layar penuh saat memakai proyektor.
          3. Slide Awal berisi tujuan pembelajaran dan pertanyaan pemantik.
          4. Slide Memahami berisi konsep inti yang dibangun bersama peserta didik.
          5. Slide Mengaplikasi memuat simulasi yang bisa langsung dioperasikan di slide.
          6. Slide Merefleksi berisi pertanyaan refleksi dan rencana pertemuan berikutnya.
          7. Tekan N untuk menampilkan catatan guru (alokasi waktu dan diferensiasi).

          Pintasan papan ketik

          TombolFungsi
          → PgDnSlide berikutnya
          ← PgUpSlide sebelumnya
          Home EndSlide pertama / terakhir
          FLayar penuh
          ODaftar slide
          NCatatan guru
          EscTutup presentasi

          Di HP atau tablet, geser layar ke kiri atau ke kanan untuk berpindah slide.

          Menerbitkan di GitHub Pages

          1. Buat repositori baru di github.com, misalnya lab-virtual-kimia-x, dengan visibilitas Public.
          2. Pilih Add file → Upload files, unggah index.html dan sw.js (keduanya di folder yang sama), lalu Commit changes.
          3. Buka Settings → Pages. Pada Source pilih Deploy from a branch, branch main, folder / (root), lalu Save.
          4. Tunggu 1–2 menit. Alamat website muncul di halaman yang sama, misalnya https://namaakun.github.io/lab-virtual-kimia-x/.
          5. Bagikan alamat itu kepada peserta didik. Tautan langsung ke satu presentasi: tambahkan #deck-1-1 (modul 1 pertemuan 1) di akhir alamat.

          Mengganti identitas sekolah

          Buka index.html dengan Notepad atau langsung di GitHub (ikon pensil), cari baris const SITE di bagian bawah file, lalu ganti nama guru, sekolah, dan tahun pelajaran. Simpan, dan website akan diperbarui otomatis.

          const SITE = {
  guru: "Nama Guru, S.Pd.",
  sekolah: "SMA Negeri ...",
  tahun: "2026/2027"
};
